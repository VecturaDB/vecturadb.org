VecturaDB

An open-source vector database, compatible with the Chroma API.

VecturaDB runs on a single node and serves the HTTP API of Chroma, so the Chroma clients connect to it.

VecturaDB is not affiliated with Chroma. It is built on Chroma, the open-source database by Chroma and its contributors. The VecturaDB repository keeps the full git history of Chroma and its Apache 2.0 license.

Python

pip uninstall -y chromadb
pip install VecturaDB

The VecturaDB package replaces chromadb. The import name stays chromadb, so existing code runs as it is. The two packages install the same modules, so they cannot be installed side by side.

import chromadb

client = chromadb.HttpClient(host="localhost", port=8000)

Docker

docker run -p 8000:8000 -v ./data:/data ghcr.io/vecturadb/vecturadb

Images for amd64 and arm64. The data lives in /data.

Binaries

Linux (x86_64 and arm64), macOS (x64 and arm64) and Windows (x64):

curl -sSL https://raw.githubusercontent.com/VecturaDB/VecturaDB/main/rust/cli/install/install.sh | bash
chroma run --path ./data

On Windows, in PowerShell:

iex ((New-Object System.Net.WebClient).DownloadString('https://raw.githubusercontent.com/VecturaDB/VecturaDB/main/rust/cli/install/install.ps1'))

Every binary is also in the releases.

Telemetry

Off by default. ANONYMIZED_TELEMETRY=TRUE turns on the anonymized telemetry inherited from Chroma, in the Python package only. The server binary sends none.
